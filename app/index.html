          Mode Auto

          • Choisissez le modèle, puis cliquez un point de départ sur une galerie : le serveur suit le modèle dans toutes les directions et le tracé (rouge) apparaît au fur et à mesure. « Nouveau départ » relance depuis un autre point en gardant le tracé.
          • Repérez une erreur et annotez par-dessus le tracé rouge comme en mode manuel, sans rien découper : clic dans le vide = premier point d'un nouveau groupe, clic = point suivant (relié au précédent), clic droit = carrefour, F = cul-de-sac, Échap = finir la branche puis clic sur un point pour repartir de là. Chaque groupe de points reliés est une « zone » ; son rectangle (points ± 32 px) sert au rapport et à l'entraînement.
          • Quelques points suffisent (un carrefour + 30–40 px par branche) ; une extrémité non marquée F est ouverte (anneau pointillé) et jamais apprise comme cul-de-sac — mais un vrai cul-de-sac oublié n'est pas appris non plus : pensez à F.
          • Retouches : glisser un point = déplacer · clic sur un segment = y insérer un point · Ctrl+clic sur un autre point = relier / délier (deux groupes reliés fusionnent) · Suppr · I = type · Ctrl+Z.
          • Annotez toutes les galeries autour d'un carrefour corrigé (une galerie oubliée = une direction fausse apprise) ; plusieurs départs du modèle et autant de groupes que vous voulez vont dans le même export. Le fichier garde la provenance (mode, modèle, version de l'app, départs, tracé complet du modèle) pour qui entraîne.

          Mode Baguette magique

          1. Cliquez dans le blanc d'une galerie : la baguette colore tout le vide relié à ce point dont la couleur reste dans la tolérance (comme la baguette de Photoshop ; un trait noir l'arrête). Zoomez (molette) sur une galerie fine : le vide n'y fait que 2–3 px.
          2. La tolérance se règle au curseur ou avec [ / ]. En automatique, elle se cale juste avant le « bond » de la courbe aire(tolérance) — c'est une heuristique, regardez la courbe.
          3. Entrée lance le modèle depuis le point cliqué ; N le fait avancer d'un pas. La rose au point rouge montre ses 32 directions (vert = retenue) et la baguette suit le point courant. Cliquez ailleurs pour sonder un autre endroit ; Échap efface la sonde.

          Règles

          • Clic : pose un point sur l’axe de la galerie, le plus loin possible sans traverser de mur (la fenêtre n’est qu’un repère : le modèle final avance à pas fixe).
          • Point normal : une seule suite → la vue saute sur le nouveau point.
          • Point intersection (Maj+clic, clic droit ou I) : posez une amorce par branche, puis Espace.
          • F : cul-de-sac → passe à la branche en attente suivante, sinon retour au départ.
          • Clic sur un point existant : jonction (zone déjà cartographiée), termine la branche.
          • Mode assisté (A, serveur lancé avec --model) : le modèle propose en violet le prochain point (ou les amorces, ou « cul-de-sac ») avec sa confiance. Entrée ou clic sur la proposition = accepter ; cliquer ailleurs / F = corriger. Chaque décision est journalisée avec la proposition.
          • Molette : zoom · glisser : déplacer la vue · C : recentrer.
