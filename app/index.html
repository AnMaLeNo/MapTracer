      Données

      Sauvegarde automatique dans le navigateur. Les crops d'entraînement se génèrent avec tools/export_dataset.py à partir du JSON.

      Règles

      • Clic : pose un point sur l’axe de la galerie, le plus loin possible sans traverser de mur (la fenêtre n’est qu’un repère : le modèle final avance à pas fixe).
      • Point normal : une seule suite → la vue saute sur le nouveau point.
      • Point intersection (Maj+clic, clic droit ou I) : posez une amorce par branche, puis Espace.
      • F : cul-de-sac → passe à la branche en attente suivante, sinon retour au départ.
      • Clic sur un point existant : jonction (zone déjà cartographiée), termine la branche.
      • Molette : zoom · glisser : déplacer la vue · C : recentrer.
